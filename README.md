# Entre clases y turnos

Mini sitio web educativo para jóvenes que estudian y trabajan a la vez y sienten estrés o ansiedad. Es un recurso digital sobre una necesidad socioemocional en contexto educativo.

## Qué incluye

- Guía de respiración animada (cuadrada 4-4-4-4 y exhalación larga 4-6).
- Calculadora "Tu semana": muestra cuántas de las 168 horas de la semana quedan libres.
- Test informal de 6 afirmaciones sobre estrés y ansiedad (no es un diagnóstico).
- Estrategias para la semana, el trabajo, la escuela y la recuperación.
- Herramienta para revisar pensamientos que exageran (modelo cognitivo).
- Bases psicológicas y opciones de ayuda.
- Frases motivadoras.

## Cómo verlo en tu computadora

Abre el archivo `index.html` en tu navegador. Usa Google Fonts, así que necesita internet para mostrar las tipografías. Sin conexión se ve con las fuentes del sistema.

## Cómo publicarlo con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `entre-clases-y-turnos`, y déjalo público.
2. Sube `index.html` y `README.md` con **Add file → Upload files** y confirma con **Commit changes**.
3. Entra a **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` con la carpeta `/ (root)` y guarda.
4. Espera uno o dos minutos. Tu sitio quedará en `https://TU-USUARIO.github.io/entre-clases-y-turnos/`.

## Bases psicológicas

- Modelo transaccional del estrés (Lazarus y Folkman, 1984).
- Modelo demanda-control (Karasek, 1979).
- Conservación de recursos (Hobfoll, 1989).
- Modelo cognitivo (Aaron Beck).
- Respiración lenta como forma de reducir la activación fisiológica.

## Aviso

Recurso educativo para jóvenes que estudian y trabajan. No es un servicio clínico ni sustituye la atención de un profesional de la salud mental.
